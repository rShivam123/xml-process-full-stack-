# CreditSea Backend

This is the backend API for the CreditSea XML Report Processor project.

## Features

- Upload XML files.
- Process and store credit report data in MongoDB Atlas.
- Fetch stored reports via API endpoints.

## Technologies Used

- Node.js
- Express.js
- MongoDB Atlas
- dotenv
- CORS

## Environment Variables

Create a `.env` file in the backend folder:

Install dependencies:
npm install

Run the backend server:
node server.js
 
 Navigate to the frontend folder:

cd frontend


Install dependencies:

npm install


Configure the backend API URL in frontend/src/App.js:

const API_BASE = "http://localhost:5000/api"; // change to deployed backend URL after deployment


Run the frontend:

npm start


The frontend will run at:

http://localhost:3000
